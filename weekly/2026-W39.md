# Week 2026-W39

## Summary
This week's work centered on turning job-tracker into a full, cost-aware job-hunting pipeline — from scouting and scoring to fitted CVs and interview prep — while tightening its targeting toward AI/dev/support roles. Alongside that, two reliability issues were caught and fixed in nexus-grind (an exposed Supabase table and an Android crash), and the portfolio site and CVs were kept in sync with the scout's evolving capabilities and priorities. A new CI test suite (API + E2E) was also stood up for job-tracker, and a new project, github-reels, began shipping automated content with DM CTAs.

## Wins
- Built an autonomous job scout with scoring, deduplication, and an inbox-review workflow, expanding coverage from ~57 to ~220 postings by fixing category-based search
- Shipped CV-fitting and interview-prep agents that tailor résumés per posting and generate company-researched Q&A briefs
- Cut AI scoring cost ~20x (420 → ~20 neurons/posting) and added per-feature daily spend budgets to prevent runaway usage
- Found and remediated a publicly readable Supabase table in nexus-grind, and discovered/fixed a never-applied RLS migration
- Fixed a recurring Android crash on Sync caused by an unregistered Health Connect permission delegate, and hardened config against future silent regressions with a smoke test
- Built a CI test suite (18 API requests/33 assertions via Postman, plus Playwright E2E) running against an isolated D1 build with no live AI spend

## Projects touched
- **job-tracker** — Built scout, scoring, CV-fitting, and interview-prep agents; cut AI costs, added budgets, re-prioritized targeting, added CI tests.
- **spidey-portfolio** — Shipped a Workers AI Q&A assistant; kept CVs and case study aligned with job-tracker's new features and priorities.
- **nexus-grind** — Fixed a public Supabase data exposure, an Android crash, and a silent desktop updater failure; added a config smoke test.
- **ErikKarasek** — Built an animated terminal-style profile README with ASCII art and a self-redrawing contribution graph.
- **github-reels** — New project: automated reel scripts from GitHub trending/AI news, with comment-to-DM CTAs.

## LinkedIn draft
This week I built out a full job-hunting pipeline for myself: a scout that scans postings daily, scores them for fit, drafts tailored CVs, and even preps interview briefs by researching the company's own site. Along the way I cut the AI scoring cost by about 20x by switching to a smaller model and parsing details in code instead of trusting the model for everything — and added spend budgets so testing runs can't burn through a day's allocation.

I also found and fixed a publicly readable database table in one of my other projects, plus a persistent Android crash that turned out to be caused by a missing permission registration. Small reminder that "it works on my machine" and "it's actually secure/stable" are two different bars to clear.

Capped the week off by wiring up a real CI test suite (API + end-to-end) so future changes don't rely on manual testing.
