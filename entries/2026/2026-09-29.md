## By project
### job-tracker
- Commute filter (`commute.ts`): keeps postings naming Hradec Králové or Pardubice, plus remote and unknown places. A region alone doesn't count.
- Priorities: IT technician, specialist, support and admin titles get priority 1, other IT, development and IS work 2, AI 3. The inbox ranks by fit score plus +10 for AI and +5 for development.
- Testing and analyst titles are lifted only by programming words, not by "consultant" or "support".
- New keyword searches for React, TypeScript, JavaScript, Node.js and junior developer run ahead of the IT fields, because the development field held only one real junior web posting in a month.
- ELDIS: server-drawn page read via a configurable posting-link class. Unicorn: read through its public `loadWebPage` JSON endpoint, which `fetchJobPosting` now uses for both the scout and the agent.
- Known server-drawn hosts pass from 1,000 characters instead of 2,500, which fixes two RETIA postings wrongly marked unreadable. Duplicate titles are now matched on letters and digits only.
- Deps: faker patched with patch-package, recorded in `auditIgnore` for the weekly report. Also `npm audit fix`.
- Synced the résumé copy so the scout's profile knows about the automation agents.
