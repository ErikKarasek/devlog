# 2026-10-01 — Thursday

**TL;DR:** Shipped Wisp — a macOS notch agent dashboard with a SwiftUI iPhone app, widgets, and Cloudflare relay — while hardening the surrounding automation tools and portfolio.

## Highlights
- Launched Wisp (formerly dispecink): a full Mac + iPhone system for monitoring and controlling AI agents from the notch, lock screen, Dynamic Island, and home-screen widgets, sideloaded via SideStore.
- Built Claude session limit guard that pauses Claude agents at 90 % usage and automatically resumes them after the reset, preventing lost work overnight.
- Shipped a Telegram-based remote control layer: task management, agent permissions, PR approvals, and morning summaries — all operable from the phone while away.
- Overhauled the nightly review pipeline so serious findings become capped, deduplicated Fixer tasks dispatched every run (not once per day), with Telegram reporting what was fixed, what got stuck, and which PRs are waiting.
- Added inbox-sweep capabilities to job-mail: spam and ads routed to Trash by sender and domain, casino scams filtered by content, with `/uklid`, `/blokovane`, and `/odblokuj` Telegram commands.

## By project

### dispecink → Wisp
- **Notch UI:** Full redesign in Grok-Bot style — tabbed in-notch chat, new-task entry, screen-edge glow during active work, failure card with retry, animated steps that slide and shimmer, mood states (love/wink/tired/sleep), roll-and-sparkles on job completion, drag-a-window-onto-the-bot to ask about it.
- **Agent crew:** Bot wears the look of whichever agent or Claude session is active; crew pills show only busy agents; 40 ready-made characters plus a gallery; six new body shapes (dome, onigiri, blob, cat, bear, bunny).
- **iPhone app (SwiftUI, sideloaded):** Notch-like hero, agent cards, full task list by status, new-task sheet, PR merge/close, limits with reset times, history, filters, home-screen widgets (Bot, Agents, Limits), lock-screen gauges, deep links via `dispecink://`.
- **Cloudflare relay:** Bridges Mac ↔ iPhone; worker monitors real error rate (5 + errors and > 1 %); relay accepts PR commands from the phone.
- **Telegram remote control:** Task creation and replies, permission grants, agent wake, agent-reply forwarding (one at a time, advances only when done), `/agenti` command, morning summary with limit states and Fixer report.
- **Safety nets:** Codex path self-heals, Paperclip auto-restarts on no-response, certificate expiry in morning summary, hook server requires per-install secret, rejects browsers and rebound hosts, one thread per request, key file set to 0600.
- **Paperclip agents:** Their Claude sessions no longer trigger notch permission prompts (was blocking each step for ~1 minute); sessions display the agent's name; permission buttons wrap instead of being clipped.
- **Claude limit guard:** Agents pause at 90 % (week: 95 %), resume automatically after reset; morning Telegram summary of Fixer results and waiting PRs.
- **Rename to Wisp:** Display name updated across Mac app, notch, menus, Telegram, iPhone app, and widgets; identifiers, keys, and relay unchanged; login item migrated once.
- **New icon:** Glowing ghost on Mac and iPhone.
- Various layout fixes: camera card width restored, question/permission cards take full width, dark agent colours readable on pills, detail pane scrollable with pinned buttons.
