# 2026-10-02 — Friday

**TL;DR:** A day of hardening the Paperclip/Wisp agent infrastructure — fixing Claude limit handling, hook-key security, and resilience bugs — plus a nightly-review sweep across five repos.

## Highlights
- Fixed the Claude limit guard in Wisp so agents blocked during a usage pause are correctly re-queued on resume, manually-resumed agents aren't double-invoked, and only near-limit runs (97 %/98 %) are cancelled rather than every paused task.
- Hardened the hook-key path in Wisp: a failed `/dev/urandom` draw now gracefully disables the server and hooks instead of silently producing a 48-zero key or crashing Tauri's setup.
- Closed nightly-review finding NEX-22 as a false positive after brute-forcing 7,770 input combinations and proving the cited inequality inversion changed no output.
- Fixed Telegram message truncation in two repos (devlog, job-mail/job-tracker) so long entries can't leave unclosed HTML tags or exceed Telegram's character limit.
- Shipped nightly-review fixes across five repos (devlog, gemini-jobs, hlidaci, job-mail, job-tracker), with four PRs merged by end of day (NEX-14, NEX-18, NEX-20, NEX-23).

## By project

### dispecink / wisp
- **Claude limit guard**: paused tasks blocked by Paperclip during a limit window are returned to the agent queue on resume; a run that was cut off is confirmed stopped so Paperclip doesn't re-block it.
- **Guard selectivity**: only agents still in `paused` status are woken on recovery — agents resumed manually during a limit window are skipped to prevent a double-invoke (PR NEX-23, merged).
- **Paperclip watchdog**: 30 s health-check grace period added before restarting, so a slow-but-alive Mac isn't mistaken for a dead process and doesn't kill running agent sessions.
- **Hook key — graceful degradation**: `key()` now returns `Option<&'static str>`; without a valid secret the server doesn't bind, `/cc/` fails closed, and hooks are left uninstalled — instead of panicking or accepting 48 hex zeros (PR NEX-18, merged, superseding an earlier `panic`-based fix).
- **Hook key — partial operation**: without a secret, `/notify` and `/focus` continue to work; only `/cc/` returns 403.
- **Rate limit threshold**: running agents are allowed to finish their turn; a run is cancelled only at 97 % (weekly 98 %), because a cancelled run is billed twice.
- New Claude agents default to Sonnet 5.5.

### devlog
- Isolated scratch folders per `agy` call so concurrent nightly-review runs can't see each other's files; folders are deleted after the run.
- Telegram messages are split at line boundaries so a long entry can never leave an unclosed `<b>` tag that Telegram would reject.

### gemini-jobs
- Verdict-less reports now keep only the last 100 lines instead of posting megabytes of narration to Paperclip (NEX-14, merged).
- Temp file `$report.tmp` is cleaned up via a `trap`, so `set -e` aborts don't leave it behind (NEX-19, open).

### hlidaci
- Refreshing a stale plan sends exactly one notification and does not trigger the quiet period (NEX-20, merged).

### job-mail
- `parseModelArray` returns `[]` and logs the reason instead of throwing when quote-repair also fails, so a broken model response no longer silently looks like a day with no mail (NEX-15, open).
- Emptying the Hromadná folder now checks `uidValidity` and moves only the mail the scan saw (NEX-21, open).
- Telegram and board HTTP requests time out instead of hanging indefinitely after the Mac wakes from sleep.

### job-tracker
- Message cards fold the brief against the actual available space, and both the company name and role are capped in the header, so a long company name can't push the card over Telegram's limit. Covered by tests (NEX-16, open).

### subscription-tracker
- Reminder emails now spell out the month name to avoid ambiguity (e.g. "10 May" vs "10/5").
